✅ **What was built today:**

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔐 **SECURITY SYSTEM**

• **Premium players** (Mojang UUID v4) → auto-authenticated on join, no password needed
• **Cracked players** (offline UUID v3, MD5 of `OfflinePlayer:name`) → must `/register` on first join, `/login` every session
• All accounts tied to **UUID permanently**, not username — name changes don't break accounts
• **Anti-spoof protection:** if an offline player's username matches a verified player's display name, the server either kicks them (configurable) or auto-suffixes their display name (e.g. `Alice_2`)
• UUID version check used to distinguish premium vs cracked at the server level — works correctly behind Velocity + AuthVelocity

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔒 **WHAT'S BLOCKED UNTIL AUTH**

• Movement (player teleported back to join position every tick)
• All block/entity interactions
• Item use
• Block breaking + attacking
• Inventory slot clicks (via Mixin — fully locked, not just events)
• Chat
• Auth timeout: configurable kick if player doesn't log in within N seconds (default 60s)
• Brute force protection: configurable max failed attempts before kick (default 5)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
👤 **PROFILE SYSTEM**

• Every player gets a profile on first join tied to their UUID
• Profile stores: display name, bio, account type, join date, total playtime, skin URL
• Display names are **globally unique across all players**
• Verified (premium) players' names cannot be claimed by offline players
• Data stored as encrypted JSON flat files in `<world>/coffeesaeroauth/` — no external database needed

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AeroSMP/
├── devlogs/YYYY-MM-DD.md          — written on server stop (or /authmod obsidianreport)
├── players/[displayname].md       — PUT on first join; re-PUT on each login/logout/achievement
├── sessions/YYYY-MM-DD.md         — PUT header on first join of day; POST timeline entries live
├── watchdog/alerts-YYYY-MM.md     — PUT header on first alert of month; POST each alert line
└── graph-data/connections.md      — PUT header once; POST each new player pair + date

TRIGGERS
Player first join    → PUT players/[name].md with frontmatter + empty sections
Player login         → re-PUT players/[name].md; ensure session file exists; POST timeline entry
Player logout        → closeSession() on InMemoryLog; re-PUT player file with updated playtime
Achievement          → append to log.achievements; re-PUT player file; POST session timeline
Watchdog alert       → POST to monthly watchdog file; append to player's watchdog flags
Two players online   → POST connection line (deduped by "name1:name2:date" set)
Server stop          → write devlogs/YYYY-MM-DD.md; rewrite today's session file

OFFLINE PLAYER DELAY
Premium players: Obsidian hooks fire immediately on join (auto-auth)
Offline players: hooks fire when /login succeeds via AuthManager.onAuthenticated()
  → calls PlayerAuthEvents.onOfflinePlayerAuthenticated(player) which calls exporter
