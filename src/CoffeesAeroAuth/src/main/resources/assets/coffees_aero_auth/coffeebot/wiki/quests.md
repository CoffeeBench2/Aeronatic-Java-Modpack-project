# Quests

**There's no quest book in Season 3 at launch.** The Season 2 book was built around
that season's mod list, and Season 3 ships a different set of mods.

If a Season 3 quest book arrives, it'll be announced in
**[Discord](https://discord.gg/AnFUh5vTz6)** and this page will be updated.
